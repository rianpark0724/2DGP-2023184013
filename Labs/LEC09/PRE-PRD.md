# 애니메이션 뷰어 기획 초안

python - pico2d 사용.
실행 파일은 단일 파일 한 개로 제한.
이름: animation_viewer.py
사용하는 파일: sonic-sprite.png

## 기능
스프라이트 시트에 있는 모든 애니메이션을 재생한다.
한 동작의 애니메이션을 5번 반복 재생 → 1초 대기 → 다음 동작.
모든 애니메이션이 재생되면 다시 무한 반복한다.
이미지의 크기는 화면에서 잘 보이도록 확대한다. 

## 구현 절차
한 번에 모든 코드를 작성하지 않고 단계별로 작성해서 최소한 20번의 커밋이 이루어져야 함.
