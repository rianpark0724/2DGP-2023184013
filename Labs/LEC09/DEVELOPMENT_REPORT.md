# LEC09 개발 및 검증 보고서

## 결과

검증 날짜: 2026-10-05, Asia/Seoul.

`animation_viewer.py` 단일 파일로 16개 동작·76개 프레임의 자동 순환 재생을 구현했다. 각 동작은 10 FPS로 5회 반복하고 마지막 프레임에서 1초 대기한다. 창 닫기 또는 Escape로 종료한다.

브랜치는 `feature/lec09-animation-viewer`이며, PRD 확정 커밋 `2dd49ee` 이후 아래의 22단계로 개발했다. 커밋 메시지는 모두 `hw_3-` 접두어와 한글 설명을 사용한다. 초기 기획 문서 커밋은 개발 22회에 포함하지 않는다.

## 실행 환경과 검증 방식

- 운영체제: Windows 64비트.
- Python: 3.12.14.
- pico2d: 1.5.1, PySDL2: 0.9.17, PySDL2-DLL: 2.32.10.
- 검증 환경: 저장소 외부의 `2dgame/.lec09-venv`.
- 앱 의존성: Python 표준 라이브러리, pico2d 및 pico2d가 설치하는 SDL 의존성.
- Pillow는 검증 도구에서 이미지 대조에만 사용했다. 앱은 Pillow나 외부 프레임 데이터에 의존하지 않는다.

검증용 스크립트와 임시 출력은 저장소 외부에서 실행했다. 앱의 상태 갱신에는 가상 시각을 주입하여 경계값을 검사했고, 실제 실행은 SDL 창과 렌더러를 사용했다. 종료 검증은 `SDL_PushEvent`로 SDL 이벤트 큐에 창 닫기·Escape 이벤트를 넣어 앱의 실제 이벤트 루프를 통과시켰다. 물리적인 키 입력 자동화와는 구분한다.

실제 두 순환의 명목 재생 시간은 `76 × 5 / 10 × 2 + 16 × 1 × 2 = 108초`다. 측정한 109.121초에는 창·이미지 초기화, 이벤트 루프 간격과 정리 시간이 포함된다. 좌표 경계 최종 수정은 프레임 수와 시간 로직을 바꾸지 않았으며, 수정 후 전체 렌더링 검사를 재실행했다.

종료 검증 초기에는 창 시작부터의 전체 시간을 6초 이내로 제한해 실패한 사례가 있었다. 이후 종료 이벤트를 넣은 시점부터 실제 반환까지 측정하도록 검증 도구를 수정했다. 네 조합 모두 위의 지연 시간 안에 정상 종료했다. 이 변경은 앱의 종료 로직 변경이 아니다.

## 재확인 방법

1. [README.md](README.md)의 명령으로 실행한다.
2. 첫 동작이 5회 반복된 뒤 1초간 마지막 포즈에서 멈추는지 확인한다.
3. 약 2분간 재생하여 동작 목록이 두 번 순환하는지 확인한다.
4. 재생 중과 대기 중 각각 Escape와 창 닫기를 확인한다.
5. 다른 폴더에서 스크립트 경로를 지정해 실행한다.
6. 커밋 이력은 `git log --reverse --oneline 2dd49ee..HEAD -- Labs/LEC09`로 확인한다.

현재 확인된 미해결 실행 오류는 없다. 실제 검증한 플랫폼은 Windows이며 다른 운영체제에서의 창·SDL 구동은 검증하지 않았다. 동작의 의미와 일부 그룹 경계에는 앞서 기록한 이미지 해석상의 불확실성이 남아 있다.
